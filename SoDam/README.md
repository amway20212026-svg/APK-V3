# SoDam – Sổ Đám

Ứng dụng Android ghi sổ người đi đám, số tiền, ghi chú, tìm kiếm và sao lưu/khôi phục JSON.

Tên hiển thị đã đổi thành **Sổ Đám**. Phiên bản Android: 2.0 (versionCode 2).

## Cloud build
Mở repository trên GitHub, vào Actions → Build Android APK → Run workflow.

## Lưu ý
Bản nguồn này giữ tính năng sổ/đám hiện có (mỗi sự kiện có danh sách riêng). Chức năng tổ chức thành sổ theo năm và lịch sử/đánh dấu đã đi là yêu cầu nâng cấp tiếp theo, chưa được triển khai trong mã nguồn phiên bản này. Hãy sao lưu JSON trước khi cập nhật ứng dụng.
