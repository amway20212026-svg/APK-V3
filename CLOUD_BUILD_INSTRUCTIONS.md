# Cloud Build – Sổ Đám

1. Tải và giải nén ZIP.
2. Upload toàn bộ nội dung (bao gồm `.github/workflows/build-apk.yml`) lên GitHub repository.
3. Mở tab Actions → Build Android APK → Run workflow.
4. Khi workflow hoàn tất, tải APK trong Artifacts.

Ứng dụng hiện mang tên Sổ Đám. Sao lưu dữ liệu JSON trong ứng dụng trước khi cập nhật.
